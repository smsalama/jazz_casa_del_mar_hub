## 4. Setup and run

`bash scripts/setup.sh` (agency template plus project steps, idempotent):

1. `scripts/doctor.sh` (git, Node.js 24.16.0 or later, npm 11 or later, curl; refuses older versions, AC-H1).
2. Git hooks on (`core.hooksPath .githooks`).
3. `npm ci` (install scripts disabled by `.npmrc`).
4. `npx playwright install chromium` (plus `webkit firefox` on macOS); skipped when the browsers are already present.
5. `.env` from `.env.example` if missing, `chmod 600 .env`.
6. `mkdir -p data backups && chmod 700 data backups`.
7. `npm run build`, then `npm run db:migrate` and `npm run seed` (seed only on an empty database).
8. Secret scanner install (agency template).

Then, on the Mac: `npm run admin:create`, `npm start`, open `http://localhost:4321`. In the workspace: `bash scripts/setup.sh --workspace`, then `bash scripts/verify.sh`.

Release package install and first run (NFR-32, at most 10 commands): unzip, `cd`, `bash scripts/setup.sh`, `npm run admin:create`, `npm start`.
