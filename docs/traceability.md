# Traceability: Jazz Casa del Mar resort website

- Task: P2-T1a (Requirements Analyst), regenerated by P2-T2 after the T1 scope approval
- Sources: `docs/requirements.md` (requirements), `docs/stories.md` (stories and acceptance criteria)
- How it is built: each active acceptance criterion in `docs/stories.md` carries the IDs of the requirements it checks in square brackets. This file is generated from those tags by script, so a requirement lists only the criteria that actually check it. "(P)" after a criterion means it is still provisional on an open item (OQ-12, OQ-20 or OQ-21). Withdrawn criteria keep their numbers and are listed in their own section; they are not counted in coverage.
- Tests column: left empty for QA to complete in Phase 8 with the test ID and result for each criterion.
- Coverage: 48 functional requirements and 36 non-functional requirements; 80 stories; 401 active acceptance criteria and 7 withdrawn (408 IDs in all); 4 active criteria still provisional. Every requirement has at least one story and at least one active acceptance criterion, every story has at least one active criterion, and every active criterion traces to at least one requirement. Re-checked by script on regeneration.
- Requirements not built in the first release but kept: FR-21 (enquiry email, US-14), FR-33 (two-step verification, US-31). FR-44 (US-42) and FR-46 (US-44) are Could in the first release and become Must before any hosting.
